# Naver Blog Assistant — 다른 컴퓨터 동기화 및 크롬 익스텐션 적용 가이드

본 가이드는 현재 작업한 브랜치(`codex/naver-assistant-v13-3-discovery-runtime-fix`)의 최신 소스코드를 **다른 컴퓨터(맥북, 데스크톱 등)**에 그대로 적용하고, 크롬 익스텐션을 정상 연동하여 실행하는 방법을 안내합니다.

---

## 1. 다른 컴퓨터에서 최신 소스코드 동기화하기

다른 컴퓨터의 터미널(Terminal / iTerm 등)을 열고 아래 명령어를 순서대로 실행합니다.

```bash
# 1. 프로젝트 폴더로 이동
cd ~/Desktop/불로구

# 2. 원격 저장소의 최신 브랜치 정보 갱신
git fetch origin

# 3. 현재 작업 브랜치로 체크아웃
git checkout codex/naver-assistant-v13-3-discovery-runtime-fix

# 4. 원격에 푸시된 최신 커밋 내려받기
git pull origin codex/naver-assistant-v13-3-discovery-runtime-fix

# 5. (선택) 새 패키지 의존성 확인
.venv/bin/pip install -r requirements.txt
```

> [!TIP]
> 만약 다른 컴퓨터에서 로컬 변경사항이 있어서 `git pull` 시 충돌 경고가 뜬다면:
> `git stash`로 임시 저장 후 `git pull`을 진행하시면 됩니다.

## 2. 크롬 익스텐션(Chrome Extension) 업그레이드 및 확인

### Q. 크롬 익스텐션도 업그레이드해야 하나요?
**A. 브라우저에서 '새로고침(🔄)'을 한 번 눌러주시면 됩니다!**

- 이번 V14 업데이트는 파이썬 백엔드(V10 프롬프트 엔진, NEED_MORE_CONTEXT 파이프라인, 내 글 답글 도우미 서비스 및 GUI)를 중심으로 고도화되었습니다.
- 기존 익스텐션 브릿지 프로토콜(`GeminiCommand`, `GeminiResult`)과 100% 하위 호환되므로 익스텐션 내부 코드가 깨지지 않습니다.
- 다만, 브라우저 메모리에 캐시된 세션을 정리하고 최신 브릿지 서버와 깨끗하게 통신하기 위해 다음 절차를 권장합니다.

### 🔄 기존 컴퓨터 / 다른 컴퓨터에서 익스텐션 새로고침 방법:
1. Chrome 브라우저를 열고 주소창에 `chrome://extensions/` 를 입력합니다.
2. 우측 상단의 **[개발자 모드]** 토글이 켜져 있는지 확인합니다.
3. 목록에서 **Naver Assistant Gemini Extension** (또는 등록된 확장 프로그램) 카드의 **새로고침(🔄) 아이콘**을 클릭합니다.
4. Gemini 웹 페이지(`gemini.google.com`) 탭을 새로고침(Cmd+R / F5)합니다.

### 🆕 다른 컴퓨터에 익스텐션을 처음 등록하는 경우:
1. Chrome 브라우저에서 `chrome://extensions/` 로 이동합니다.
2. 우측 상단 **[개발자 모드]**를 켭니다.
3. 좌측 상단의 **[압축해제된 확장 프로그램을 로드합니다]** 버튼을 클릭합니다.
4. 파일 탐색기에서 `~/Desktop/불로구/chrome_extension` 폴더를 선택하여 등록합니다.

## 3. 프로그램 실행 및 동작 확인

다른 컴퓨터에서 아래 명령어로 GUI를 실행합니다:

```bash
cd ~/Desktop/불로구
.venv/bin/python main.py
```

### 실행 후 확인 사항:
1. 메인 화면 탭에 `💬 내 글 답글 도우미` 탭이 정상 노출되는지 확인합니다.
2. 상단 블로그 ID 입력 후 `[글 목록]` 클릭 시 최근 글이 날짜 및 댓글 수와 함께 로드되는지 확인합니다.
3. 특정 글 클릭 시 댓글 스레드가 계층별로 로드되며, 미답글 노드에 `[🔄 재생성]`, `[📋 복사]`, `[✍️ 답글창]` 버튼이 지원되는지 확인합니다.
4. `[미답글 추천 생성]` 클릭 시 Gemini 배치 생성과 정밀한 매핑이 정상 동작하는지 확인합니다.
