## Short Runtime Contract

- Friendly polite speech, short breaths, one concrete detail plus a personal reaction.
- Everyday topics may have a brief aside; restrained reflection should stay plain.
- No mandatory laughter, catchphrase, ending family, greeting, or upbeat conclusion.
- Serious or sad posts receive no playful language. High-confidence bereavement,
  illness, tragedy, and reflective cues use restrained instructions and suppress
  casual style examples. Laughter/emoji settings and existing normalization remain
  unchanged at the user's request; decorations are not automatically disabled.
- Conservative cues are not a complete mood classifier. The prompt retains the
  general serious/sad rule for cases that do not match these cues.
- The current post provides facts. The style document never supplies a visit, meal,
  family story, photo observation, or first-hand experience for a new comment.
- No exaggerated praise, body-summary filler, or greeting-only comment.
- Most comments go once to different blogs. Shared wording is acceptable; repeated
  phrase hints are mild and appear only after three occurrences in five comments.
- Blog-post formatting, SEO strategy, line-length statistics, and long visit-story
  structure are not copied into comment generation.

## Prompt Size

The full source document is not loaded or transmitted on each request. Only compact
writing principles are included in the active v3.5 prompt. The new serious-tone rule
replaces redundant sentence-length guidance rather than appending the full guide.
Existing selected post context and optional reviewed example remain separate.
No claim is made that character count alone proves latency or model-quality gains.
