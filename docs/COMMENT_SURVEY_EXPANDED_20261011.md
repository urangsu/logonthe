## 문체에 적용할 해석

1. 질문 글에는 질문에 답하고, 실패 글에는 아쉬움에 호응했다. 매번 칭찬으로
   바꾸거나 음식 조합을 설명할 필요가 없다.
2. 짧은 구어체도 자연스러웠다. 두 번째 문장에 방문 의향/위로를 덧붙이면
   오히려 상투적이 될 수 있다.
3. 웃음이나 이모지가 없어도 충분히 자연스럽다. 그렇다고 사용자 설정을 끄거나
   이 표본의 비율을 그대로 생성 확률로 적용하지 않는다.
4. 친밀한 반말, 결혼 농담, 문 열어 달라는 농담은 기존 관계가 전제된다.
   처음 방문한 네이버 블로그에 그대로 이식하지 않는다.
5. 사람의 실제 경험담은 모델의 경험이 아니다. 방문/시식/가족 사연을 복사하지 않는다.
6. 독자의 과장, 관계 추정, 검증되지 않은 식품 조언도 있었다. 실제 댓글이라는
   이유만으로 바람직한 학습 예시로 승인하지 않는다.

원문 대량 주입 대신 위의 문맥별 반응 원리를 검토 자료로 사용한다.
사용자 승인 학습 데이터, 자동 등록 설정, 실제 댓글은 이번 조사로 변경하지 않았다.
