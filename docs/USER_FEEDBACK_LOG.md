# 사용자 피드백 기록

이 문서는 Naver Blog Assistant V1.1 작업 중 사용자가 지적한 요구와 그에 따른 수정 근거를 기록한다.

## 2026-08-27

### 요구와 비판

- 기존 앱보다 자동화를 원했는데, 안전 모드를 강제로 적용하면서 기능을 축소한 것은 요구와 반대되는 회귀였다.
- ChatGPT 또는 기존 웹 AI 창에 프롬프트를 자동 입력하고 결과를 복사해 댓글창까지 넣는 흐름이 필요하다.
- 공감은 글에 들어간 뒤 설정한 난수 시간 후 자동으로 눌러야 한다.
- 행동 사이, 다음 글 사이, 랜덤 휴지 시간은 사용자가 직접 조정할 수 있어야 한다.
- 네이버 글 대부분이 잠금·동적 DOM이므로 본문을 사용자에게 직접 발췌하게 하면 안 된다. 본문은 프로그램이 자동으로 가져와야 한다.
- 앱을 종료해도 네이버 로그인 상태가 유지되어야 한다.
- main 브랜치에는 바로 병합하지 않고 기능 브랜치에 별도로 기록·푸시해야 한다.

### 반영 내용

- `assistant_mode=false`를 선택하면 기존 `PostProcessor` 경로를 사용하도록 복원했다.
- 자동화 모드에서 공감, 행동 간 대기, 다음 글 대기, 랜덤 휴지를 다시 연결했다.
- Gemini 자동 입력·응답 복사·댓글창 삽입 경로를 기존 브리지와 연결했다. 최종 등록 확인 절차는 유지한다.
- 본문 추출기가 네이버 전용 컨테이너, 구형 iframe, PC 레이아웃, 표시된 본문 fallback을 자동 탐색한다.
- 설정 화면에 자동화 모드, Gemini 브라우저 모드, 행동·다음 글·랜덤 휴지 활성화와 수치 입력을 추가했다.
- 브라우저 프로필을 기존 `data/user_profile`로 통일해 이전 버전 로그인 쿠키를 재사용한다. 기존 `data/browser_profile`은 삭제하지 않았다.
- 변경은 `codex/naver-assistant-v11` 브랜치에만 커밋·푸시했다. 사용자 설정 `config.json`은 커밋하지 않았다.

### 남은 실환경 확인

- 실제 네이버 계정에서 로그인 쿠키가 재실행 후 유지되는지 확인 필요
- 일반 Chrome의 Gemini 로그인과 Apple Events JavaScript 허용 확인 필요
- 네이버 실제 게시글에서 본문 자동 추출, 공감 클릭, 지연값 적용 확인 필요
- ChatGPT 웹 자동화는 기존 코드의 Gemini 경로와 별도이므로 ChatGPT를 대상으로 하려면 별도 DOM 브리지 검증 필요
