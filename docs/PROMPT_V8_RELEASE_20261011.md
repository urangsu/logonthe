# 댓글 프롬프트 v8 반영

## 근거와 범위

[실제 Gemini 20회 비교](GEMINI_PROMPT_AB_20_20261011.md) 및
[공개 댓글 추가 267개 조사](COMMENT_SURVEY_EXPANDED_20261011.md)를 바탕으로
v3.5 경로를 `user-voice-context-v8-compact-emotion-boundary`로 수정했다.
이전 v7/느슨한 지시의 20회 비교를 v8 결과라고 부르지 않는다.

- 반응 하나를 짧게 남기고 끝내도록 안내한다. 본문 밖의 일반적 연상과 가벼운 비유는 허용한다.
- 작성자의 좋고 아쉬운 감정을 보존하고, 없는 사실·사진 묘사·방문·시식 경험을 만들지 않게 안내한다.
- 웃음·이모지를 끄지 않는다. 기존 정책의 허용 여부, 합계 상한, 길이, 문장 수와 마침표 설정을 짧게 렌더링한다.
  특정 웃음/이모지 예시를 매번 나열해 같은 장식으로 유도하지 않는다.
- 진지한 글에만 장난·조언·종교적 가정·억지 위로·교훈을 피하는 안내를 추가한다.
  재작성할 때도 이 안내를 유지한다.
- 보조 안내는 재작성 > 반복 경고 1개 > 검토된 관련 예시 1개 > 반응 방향 순으로 하나만 넣는다.
  진지한 글에는 일반 말투 예시/반복 경고/들뜬 반응 방향을 넣지 않는다.
- 관련 예시는 간단한 어휘 겹침으로 선정한다. 관련 후보가 없으면 생략한다.
  이 휴리스틱은 의미 유사도 모델이 아니므로 관련 예시를 놓칠 수 있다.
- 음식 조합 설명/향후 방문/먹고 싶은 마음을 매번 요구하지 않는다.

외부 댓글은 검토 자료일 뿐 사용자 승인 학습 코퍼스에 넣지 않았다.
로그인 프로필, 브리지, 자동 등록, 시간, 좋아요, 필터, UI 및 후처리 확률은 변경하지 않는다.
v3.4 이하 경로도 변경하지 않는다. 프롬프트가 사실 오류를 완전히 방지한다고 주장하지 않는다.

## 검증

동일 만두 입력(웃음·이모지 허용, 명시 반응 방향, 이력/예시 없음):
이전 v7 비교 프롬프트 502자 → v8 418자. 공백 포함 문자 수이며 토큰/속도 측정이 아니다.
진지한 반려견 입력은 405자 → 385자. 본문을 잘라 길이를 줄이지 않았다.

관련 테스트로 문체 옵션, 감정/사실 경계, 보조 안내 우선순위, 진지한 글의
재작성, 근거 부족 반환, 학습/문법/품질 파이프라인 회귀를 확인한다.
최신 원격 브리지 복구 커밋을 포함한 별도 체크아웃에서 관련 테스트 134개와
하위 테스트 71개가 통과했다. `git diff --check`도 통과했다.

v8 자체의 실제 Gemini 재생성 및 네이버 등록 E2E는 이번 반영에서 실행하지 않았다.
관련 테스트 통과와 실제 댓글의 자연스러움은 별개의 검증이다.
