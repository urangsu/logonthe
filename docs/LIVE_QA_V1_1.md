## 네이버 수집 승인

- [ ] 실제 계정과 요청한 내 블로그의 일치 확인.
- [ ] 이웃 표의 ID·닉네임·그룹·추가일·새글소식 열을 원화면과 대조.
- [ ] 실제 ON 및 OFF 각 3행 이상 대조. 새글소식과 푸시 알림을 분리.
- [ ] 필터가 전체인지 확인하고 모든 페이지를 이동. 표시 총원·수집 고유 ID·목록 끝 증거 일치.

- [ ] 공감자 0명·1명·다중 페이지·숫자 미표시·메뉴 링크 혼입 대조.

- [ ] 일부 페이지 실패, 반복, 취소, 로그인 만료 시 partial/failed/cancelled 및 unknown 유지.
