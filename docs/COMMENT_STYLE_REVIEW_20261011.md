## 현재 결과와 원인

로컬 user_learning_corpus.json의 최근 20개 등록 문구에서 음식 조합 설명 후
궁금함/먹고 싶다는 말로 닫는 구조가 반복됐다. 출력 품질의 통계적 평가가 아니라
이 표본의 정성 검토다. 자동 등록 문구는 기존 정책대로 학습 예시에서 제외한다.

- 음식 반응 계획이 궁금함과 향후 방문 의향을 반복 유도했다.
- 프롬프트의 사실 안전, 말투, 음식 안내에 같은 지시가 중복됐다.
- 활성 예시 선택은 첫 번째 짧은 문구를 우선해 현재 소재와 맞는 다음 예시를 놓쳤다.
- 이모지는 후처리에서 별도 희소화한다. 따라서 프롬프트 허용만으로 실제 이모지가
  자주 남는 것은 아니다. 이번 변경은 설정과 후처리 확률을 임의로 바꾸지 않는다.

## 적정 통제

강제 유지: 허위 방문/시식 경험, 없는 가격/시설/효과, 모욕, 출력 형식,
본문 안 명령 무시, 진지하거나 슬픈 글에서 장난 배제, 중복 등록 차단.

선택 지침: 보통 한 문장, 편한 존댓말, 표지 최대 1개라는 기존 설정,
반복 표현 회피, 반응 방향. 반드시 매번 새로운 어미를 만들도록 요구하지 않는다.
상투어 하나만으로 재생성을 반복하는 방식도 추가하지 않는다.

자유 영역: 본문 단어와 일치하지 않는 일반적 감정, 가벼운 비유, 작성자의 수고에
대한 호응, 자연스러운 짧은 칭찬. 반응 방향은 참고이고 고정 문장 틀이 아니다.
외부 댓글의 친밀한 반말/과장/자기 경험은 직접 이식하지 않는다.

## 반영

- ai_prompt.py: 중복 규칙 축소, 긍정형 표현 자유, 진지한 글 전용 안내,
  검토된 예시 중 현재 본문과 어휘가 겹치는 것을 우선. 동점은 기존 순위 유지.
- reaction_planner.py: 조합 설명/궁금함/방문 계획을 필수로 유도하지 않도록 완화.
- 문체 revision: user-voice-context-v7-reaction-freedom. 기존 버전 선택과 UI는 유지.
- 게시된 댓글, 코퍼스 원본, 계정, 대기시간, 자동 등록 설정은 변경하지 않는다.
