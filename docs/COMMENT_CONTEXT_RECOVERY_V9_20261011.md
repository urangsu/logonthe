# 댓글 컨텍스트 및 반응 복구 v9

## 반영 순서

1. `naver/content_extractor.py`: 현재 글과 무관한 SmartEditor 링크 미리보기 및 숨겨진 내용을 DOM 단계에서 제외한다. 일반 인라인 링크와 문단 순서는 보존한다. iframe을 포함한 본문 후보가 있으면 페이지 전체 텍스트 폴백은 사용하지 않는다.
2. `app/processor.py`, `services/comments/community_rhythm.py`: 짧은 음식 앵커 목록에서 빠진 본문 메뉴를 다시 확인한다. '조합/궁금'이라는 단어만으로 통과시키지 않는다. 부사나 관형형 동사를 메뉴로 오인하지 않도록 속성 대상 범위를 좁히고, 동일 속성이 해당 메뉴에도 명시된 경우는 허용한다.
3. `services/reaction_planner.py`: 두 메뉴를 묶는 문장 대신 눈에 들어온 부분과 느낌 하나를 권한다. 음식 후기도 작성자의 아쉬움을 우선하며, 혼합 평가와 부정된 아쉬움을 구분한다. 해당 감정에 호응하는 댓글은 메뉴명을 반복하지 않아도 본문 감정 근거로 검사한다.
4. `services/comments/style_normalizer.py`: 최근 등록 이력에서 같은 이모지의 반복만 제한한다. 다른 이모지를 임의로 치환하거나 추가하지 않는다. 기존 단일 이모지 샘플링, 과장형 제거, 단위 보존은 유지한다. 이력 창 0은 이력 검사 비활성화로 처리한다.

## 설정 및 호환성

- 프롬프트 식별자: `user-voice-context-v9-grounded-reaction`
- 기본 프롬프트를 늘리지 않고 반응 방향과 검증 경로를 수정했다.
- 웃음과 이모지 설정, 로그인 프로필, 피드 순서, 목표 수, 대기시간은 변경하지 않았다.
- 명시적인 `allow_soft_emoji=false`를 출력 후처리가 다시 활성화하지 않도록 했다.
- 실행 중인 프로세스에는 소스 변경이 자동 적용되지 않는다. 적용에는 현재 작업 종료 후 앱 재실행이 필요하다.

## 검증 범위

- 공개 사이트나 계정에 접속하지 않는 Chromium DOM fixture: 신형/구형 링크 미리보기, 일반 링크, 숨겨진 텍스트, legacy iframe 본문 우선순위.
- 로그 문장 회귀: 트러플 피자 반응, 보쌈김치 앞 '바로' 오탐, 실제 반찬 속성 전이, 혼합 감정.
- 프로세서 모킹 통합: 서로 다른 이모지 보존, 같은 이모지 반복 제한, 명시적 비활성 설정 존중, 에디터 주입 경로.
- 런타임 리포트를 덮어쓰는 `test_06_full_simulated_pipeline_5cases_and_report`는 제외한다.
- 실제 Gemini 출력, 실제 게시글 DOM, 서버 댓글 등록은 이번 검증에 포함하지 않는다. 따라서 자연스러움의 실전 개선 정도는 아직 확정하지 않는다.

## 남은 별도 점검

- 추상적인 공감 표현까지 경험 암시로 판정하는 기존 규칙은 이번 속성/음식 오탐 수정과 별개로 남아 있다.
- Gemini 제출 상태 불명확 및 최종 실패 집계 문제는 이번 네 가지 변경 범위에 포함하지 않았다.
